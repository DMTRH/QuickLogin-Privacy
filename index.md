# Privacy Policy – QuickLogin BETA

**Effective Date:** November 10, 2026

## 1. Introduction

QuickLogin BETA is a Chrome extension designed to simplify two-factor authentication (2FA) by generating and filling authentication codes on supported CUNY login pages.

Your privacy and the security of your authentication information are important to us. This Privacy Policy explains what information QuickLogin collects, how it is used, and how it is stored.

## 2. Information We Collect

QuickLogin may store the following information provided by users:

- **Account Names:** Names assigned by users to identify their authentication accounts.
- **TOTP Secret Keys:** Base32 secret keys entered by users to generate time-based one-time passwords (TOTP).

These details are provided voluntarily by users when setting up an account in the extension.

## 3. How We Use Information

The information stored by QuickLogin is used exclusively to:

- Generate time-based authentication codes.
- Identify accounts saved by the user.
- Automatically fill authentication codes on the supported CUNY login page.

QuickLogin does not use this information for advertising, analytics, profiling, or unrelated purposes.

## 4. Data Storage and Sharing

QuickLogin uses Chrome's storage functionality to store account names and TOTP secret keys.

The extension does not operate its own server or database for storing user authentication information.

QuickLogin does not sell, rent, or share users' account names or TOTP secret keys with third parties.

Authentication information is not transmitted to the developer.

## 5. Permissions

QuickLogin requests the following Chrome permissions:

- **Storage:** Used to save account names and TOTP secret keys.
- **Clipboard Write:** Used to support copying authentication codes when requested by the extension.
- **CUNY Website Access:** Used to interact with the supported CUNY login page and provide authentication code autofill functionality.

These permissions are used only to provide the extension's functionality.

## 6. Data Security

QuickLogin is designed to minimize access to user information and keep authentication information within the user's browser storage.

Users should treat their TOTP secret keys as confidential authentication credentials and should not share them with others.

## 7. Data Retention and Deletion

Users can remove saved accounts and their associated TOTP secret keys through the extension.

Uninstalling the extension may remove its locally stored extension data, subject to Chrome's storage behavior.

## 8. Children's Privacy

QuickLogin is a general-purpose authentication utility and does not knowingly collect personal information from children.

## 9. Changes to This Privacy Policy

This Privacy Policy may be updated when the extension's functionality or data practices change. Any significant changes will be reflected in the updated policy.

## 10. Contact

For questions or concerns regarding this Privacy Policy, users can contact the developer through the contact information provided on the QuickLogin BETA Chrome Web Store listing.

## 11. Google Chrome Web Store Limited Use Disclosure

QuickLogin's use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

User information is used only to provide the extension's authentication functionality. It is not sold, used for advertising, or transferred to third parties for unrelated purposes.
